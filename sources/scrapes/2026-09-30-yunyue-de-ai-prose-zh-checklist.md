# 反 AI 腔自查清单（中文小说 / 文案）

> **一句压舱总纲**：用具体抵达深刻；在最想煽情 / 拔高的地方后退一步，把「命名情绪、解释意义」的权力交还读者。越是悲恸或崇高，文字越要冷、越要落到一件摸得到的东西上。

本清单分两部分：
- **A. 反 AI 腔清单（11 条 + 落地自查）**——力求客观，是各类中文 AI 生成 / 翻译腔最常犯的套路。
- **B. 中文 prose 法则（10 条）**——通用写作工艺。

⚠️ **关于「好文风」**：本清单只负责揪「一眼假的 AI 套路」，**不替你定义什么是好文风**。长句流水还是短句碎句、华丽还是冷峻，是口味，请按自己的审美校准——详见仓库 README「通用规则 vs 个人口味」。

## A. 反 AI 腔清单（最常犯，写完逐条自查）

每条格式：**反例（AI 腔）→ 改写（落到具体）**。

1. **否定—修正句（头号惯犯，叙述里近乎零容忍）**——凡以「不是」起头领出修正，三种变体一并禁：「不是 X，而是 Y」「不是 X，是 Y」「不是 X。是 Y。是 Y。」（断续揭示式最毒）。
   - ❌ 他握紧的不是剑，而是十年的执念。 → ✅ 他握紧剑。剑跟了他十年。
   - ❌ 那不是恨，是被给予过的。 → ✅ 那是被给予过的东西，与恨无关。
   - ❌ 不是那些人杀了她。是他。是他这一身扎眼的本事。 → ✅ 动手的是那些人，可真正害死她的，是他自己，是他这一身扎眼的本事。
   - **改法三选一**：①删负面项、只陈述正面（最佳）；②倒装成「Y，不是 X」（正面起头，否定作尾随补语）；③换别的转折——「自以为…其实…」「不图…图…」「别去…要…」「何止…—是…」「哪里是…—是…」。**变着花样改，别让清理本身变成新套路。** 对白里偶发的「不是 A，是 B」可酌留一两处，叙述中近乎清零。

2. **三连排比 / 三短句堆砌「没有 A，没有 B，没有 C」**
   - ❌ 没有风，没有声音，没有一丝光。 → ✅ 风停了，山谷黑得发闷。

3. **明喻滥用「仿佛 / 像…一般 / 一样」**
   - ❌ 剑气仿佛巨龙，像要撕裂天空一般。 → ✅ 剑气压下来，天像要裂。（能用隐喻 / 直陈就别明喻）

4. **口头禅「在…那一刻」「终于」「连…都 / 也」**
   - ❌ 在剑触咽喉的那一刻，他终于明白，连呼吸都成奢望。 → ✅ 剑抵住咽喉。他不敢喘。

5. **破折号造「伪深刻」金句**
   - ❌ 他懂了——所谓修行，不过与孤独为伴。 → ✅ 修行这条路，说到底是熬孤独。

6. **抽象情绪概括「一种说不出的 XX」「无尽的 XX」「难以言喻的 XX」**
   - ❌ 心中涌起难以言喻的苍凉。 → ✅ 他站着没动，风把袖子吹鼓了。

7. **空洞崇高 / 玄虚辞藻（亘古 · 永恒 · 苍穹 · 至理 · 万物）**
   - ❌ 那是超越生死、亘古不变的天道至理。 → ✅ 师父只说四个字：该来的来。

8. **通篇短句单行扮「高级」**（注：这是「凑高级感」的滥用，不是说短句不好——见 §B.2）
   - ❌ 他来了。/ 带着剑。/ 和十年的恨。 → ✅ 他带着剑来了，背着十年的恨。

9. **做作动词「唤」**——叙述里把「叫 / 喊 / 称 / 取名」一律写成「唤」，矫情。固定词「唤醒 / 召唤」可留，其余几乎全换。
   - ❌ 村人从此唤他阿岩。/ 这柄唤作惊鸿的剑。 → ✅ 村人从此叫他阿岩。/ 这柄叫作惊鸿的剑。

10. **解说体 / 升华 closer「这便是…的方式：」「这便是 X。这便是 Y。」「如此，便已足够」**——把场面写成论文小结。
    - ❌ 这便是那道白光降临的方式：它从不亲自杀人……如此，便已足够。 → ✅ 那道白光从不亲自杀人。它只消叫满城的恨平息下去。（删头删尾，落回叙述）

11. **对冲式比喻「像在 X，又像在 Y」**——同一人物连用即口癖。真两可（像字又像图）可留；纯犹豫的删一头，或换「半是…半是…」「也不知是…还是…」。

### 第二批（同样高频，源自长篇实战）

12. **「第一次 / 头一回 / 头一次」滥用**——反复强调「这是第一次」。真·首次可留，但密度要低；删情绪填充，换「头一遭 / 破天荒 / 这才 / 终于」或直接砍。

13. **单字文言动词「应 / 拒 / 许」**——把「答应 / 拒绝 / 许诺」写成「他应了」「没有应也没有拒」「你许我的」，诡异。改回「答应 / 拒绝 / 点头 / 给 / 许给」。（「应了一声」「没有人应他」这类呼应义自然，可留。）

14. **怪词怪搭**——如「一寸寸矮下去」（人 / 声音 / 情绪「矮下去」不通）。下笔即自问「这是人话吗」，改通顺动词（沉 / 塌 / 低）。

15. **自创母题词 / 口头禅堆砌**——把某个自造词或爱用词刷满全文（动辄几十处）。任何母题词都怕用滥，**宁少而狠**：保留概念，把重复的描写换成有变化的说法（同义轮换）。完稿前自己列一张「我这稿的爱用词黑名单」，逐个数密度。

16. **标点把句子剁碎 / 顿号误用**
    - **顿号「、」只连并列词语**（金、木、水、火）；**并列分句 / 谓语用逗号**——错例「攥了很久、攥得太熟、连命都…」「答应过、却没守住」，一律改逗号。
    - **逗号别把句子剁碎**：最毒是副词 / 连接词被双逗号包成伪停顿——「，极轻地，」「，缓缓地，」「，第一次，」「，终于，」「，到底，」。去掉尾逗号让状语贴住动词（「他极轻地落在」而非「他，极轻地，落在」）。

17. **概念 / 强调引号滥用**——只给「临场对白」（角色当场开口说的话）留引号；一切概念 / 强调 / 术语 / 嵌入式引语全去引号，读作自然转述即可。（中文写作里，单引号 `'…'` 几乎必是概念引号，可整批清。）

## ✅ 写完自查（逐条搜 / grep）

> 这些 pattern 只做**定位**，命中后仍需肉眼判断——尤其否定修正句、引号、第一次，机器分不清对白与叙述。
> 命令以 [ripgrep](https://github.com/BurntSushi/ripgrep)（`rg`）为例；没装可用 `grep -nE` / `grep -nP` 平替。把 `稿子.md` 换成你的文件。

```bash
# 1. 否定—修正句（头号惯犯）——命中后人工判断叙述/对白
rg -n '不是.{0,30}(而是|，是|。是|，却是)' 稿子.md

# 2. 做作"唤"（排除 唤醒/召唤）
rg -n '唤' 稿子.md | rg -v '唤醒|召唤'

# 3. 解说体/升华 closer
rg -n '这便是|便已足够|如此.{0,4}便|这就是.{0,6}的方式' 稿子.md

# 4. 明喻 / 对冲比喻
rg -n '仿佛|像.{0,20}(一般|一样)|像.{0,15}又像' 稿子.md

# 5. 口头禅「那一刻 / 这一刻 / 终于」
rg -n '那一刻|这一刻|终于' 稿子.md

# 6. 破折号金句（数量，能换句号就换）
rg -nc '——' 稿子.md

# 7. 抽象情绪概括
rg -n '一种.{0,8}的|无尽|难以言喻|某种.{0,8}的|说不出的' 稿子.md

# 8. 冗副词 / "地"字结构
rg -n '狠狠|深深|默默|缓缓地|轻轻地|静静地' 稿子.md

# 9. 「第一次 / 头一回」密度
rg -nc '第一次|头一回|头一次' 稿子.md

# 10. 单字文言动词
rg -n '他应了|没有应|你许我|许我的' 稿子.md

# 11. 怪搭「矮下去」类（按需扩词）
rg -n '矮.{0,2}下去' 稿子.md

# 12. 伪停顿逗号（状语被双逗号包住）
rg -n '，[^，。！？]{1,4}地，' 稿子.md
rg -n '，(终于|忽然|到底|便|却|竟|第一次)，' 稿子.md

# 13. 半角逗号混入中文（标点不规范）
rg -n '[\x{4e00}-\x{9fff}],[\x{4e00}-\x{9fff}]' 稿子.md

# 14. 概念单引号（中文叙述里几乎必是概念引号）
rg -n "'[^']{1,12}'" 稿子.md
```

**通改顺序建议**：①否定修正句叙述清零、对白克制 → ②删升华 closer、伪深刻金句 → ③明喻 / 对冲砍到必要 → ④抽象概括换成动作景物 → ⑤删冗副词与「地」 → ⑥标点（顿号 / 伪停顿 / 半角逗号 / 概念引号）→ ⑦最后**朗读一遍**，凡翻译腔、说明书感的句子重写成顺口中文。

## B. 中文 prose 法则（10 条）

1. **强动词替形容词**（「饭划进嘴里」，不是「急切地吃」）。
2. **长短句交错制造呼吸**；短句作重音（这是「用」短句，不是「堆」短句——区别于 A.8）。
3. **白描优于抒情**：写事实与动作，让情绪从缝里渗。
4. **意象承重**：用具体物象（高粱 / 雪 / 棋 / 麦穗）扛抽象。
5. **删副词**，尤其「地」字结构。
6. **情感越大用词越钝**（写处决之后，只一句「返回的漫漫长路却似乎愈加寒冷」）。
7. **视点要稳**，距离推拉要有意为之。
8. **留白**：说尽即死。
9. **名词具体化**（「驯鹿 / 草绿军装」，不是「动物 / 衣服」）。
10. **节奏服务情绪**：紧张用断句，舒缓用流水句。
