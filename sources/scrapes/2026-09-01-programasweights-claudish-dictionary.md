## Defined terms (excerpt)

- **load-bearing**: so important that everything else depends on it. … if the load-bearing part fails or changes, the rest may no longer work.
- **seam**: where two parts of a program connect.
- **land / landed**: merge a code change.
- **drift**: gradually stop matching over time.
- **spine**: the central structure that organizes and connects the rest.
- **blast radius**: how many other things could be affected if it fails.
- **belt-and-suspenders**: an extra safeguard in case the first one fails.
- **gated on**: blocked until a requirement is met.
- **one honest caveat** / **the honest shape** / **you're right to push back**: reassurance constructions.
- **thread / wire / plumb through**: pass something through every relevant part.
- **wedged**: stuck, or making something else get stuck.
- **cadence / canonical / contract / provenance / substrate / surface**: frequent register vocabulary.
