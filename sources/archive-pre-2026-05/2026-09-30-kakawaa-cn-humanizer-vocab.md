# 中文AI词汇表——需要警惕的词和短语

在AI生成的中文文本中出现频率远高于人类写作的词汇和短语。按类别和严重程度分级。

## 一级高频词（铁证）

这些词在AI生成的中文中出现率是人类写作的5-20倍。单独出现就可疑，密集出现几乎可以确认是AI。

| 词 | 为什么是信号 | 替代说法 |
|----|------------|---------|
| 赋能 | 互联网黑话之王 | 帮、支持、给...用上 |
| 深耕 | AI最爱用的动词之一 | 做了很久、专注于 |
| 聚焦 | 几乎每篇AI文章都有 | 关注、盯着、主要做 |
| 助力 | 企业软文标配 | 帮、推动 |
| 打造 | 什么都能打造 | 做、建、搞 |
| 引领 | 谁都在引领 | 带头、领先 |
| 全方位 | 假大空修饰语 | 各方面、（具体说哪些方面） |
| 多维度 | 同上 | （直接说哪几个维度） |
| 高质量 | 空洞形容词 | （用数据说明质量） |
| 沉浸式 | 互联网黑话 | （描述具体体验） |
| 一站式 | 营销用语 | 全包、什么都有 |
| 闭环 | 管理黑话 | 从头到尾、形成循环 |
| 抓手 | 官腔 | 切入点、办法、工具 |
| 底层逻辑 | 伪深度 | 根本原因、核心原理、说白了 |
| 顶层设计 | 官腔 | 整体规划、大方向 |
| 新质生产力 | 政策黑话 | （说具体是什么技术/产能） |
| 降本增效 | 企业八股 | 省钱、提效率 |
| 提质增效 | 同上 | 做得更好更快 |
| 数智化 | "数字化+智能化"的造词 | 数字化、用上了AI |

## 二级高频词（密集出现可疑）

单个出现正常，但一段话里出现3个以上就很AI。

| 词/短语 | 替代说法 |
|---------|---------|
| 此外 | 还有、另外、（直接说） |
| 另外 | 还有、（直接接着说） |
| 值得注意的是 | （删掉，直接说） |
| 值得一提的是 | （删掉，直接说） |
| 毫无疑问 | 确实、没错 |
| 不言而喻 | 明摆着、显然 |
| 众所周知 | 大家都知道、（删掉） |
| 不可否认 | 确实、是 |
| 与此同时 | 同时、而且 |
| 事实上 | 其实、实际上 |
| 总的来说 | （删掉或直接说结论） |
| 综上所述 | （删掉） |
| 不难发现 | （删掉，直接说发现了什么） |
| 由此可见 | 所以、可见 |

## 宣传腔词汇

读起来像新闻通稿或企业软文。

- 亮眼、亮眼成绩
- 瞩目、引人瞩目
- 欣欣向荣
- 蓬勃发展
- 硕果累累
- 令人振奋
- 可圈可点
- 有目共睹
- 蒸蒸日上
- 日新月异
- 突飞猛进
- 如火如荼
- 方兴未艾
- 势不可挡

## 意义拔高短语

把普通事说成大事的套话。

- "具有里程碑式的意义"
- "标志着...的新篇章"
- "开创了...的先河"
- "翻开了...的新一页"
- "谱写了...的新华章"
- "具有划时代的意义"
- "为...注入了新的活力"
- "为...提供了有力支撑"
- "为...奠定了坚实基础"
- "树立了...的新标杆"

## 万能开头套话

AI最爱用的段落开头。

- "随着...的不断发展"
- "在当今...的时代"
- "在...的背景下"
- "作为...的重要组成部分"
- "从...的角度来看"
- "近年来"（单独使用正常，配合其他AI词就可疑）
- "众所周知"
- "毋庸置疑"

## 万能收尾套话

AI结尾三件套。

- "让我们拭目以待"
- "未来可期"
- "前景广阔"
- "大有可为"
- "值得期待"
- "充满无限可能"
- "我们有理由相信"
- "相信在未来"
- "站在新的起点上"

## 客服/机器人短语

对话场景中AI的痕迹。

- "以下是关于...的介绍/分析/回答"
- "针对您的问题"
- "根据您的需求"
- "希望以上信息对您有所帮助"
- "如有疑问请随时咨询"
- "非常感谢您的提问"
- "不客气，很高兴能帮到您"
- "以上供参考"
- "仅供参考"
- "一家之言，仅作抛砖引玉"
- "不当之处敬请指正"
- "水平有限"

## 过度连接词

人类写作中连接词使用率远低于AI。

| 过度使用 | 人类怎么做 |
|---------|-----------|
| "此外，..." | 直接说下一句 |
| "与此同时，..." | 同时、而且、或者不加连接词 |
| "不仅如此，..." | 直接说 |
| "更重要的是，..." | 直接说 |
| "除此之外，..." | 还有 |
| "值得注意的是，..." | 删掉 |
| "毫无疑问，..." | 删掉 |
| "不可否认，..." | 确实 |

## 伪深度词汇

让内容看起来有深度但实际空洞的词。

- 底层逻辑 → 根本原因
- 认知升级 → 学到了新东西
- 思维模型 → 想法/方法
- 元认知 → 反思
- 第一性原理 → 从头想
- 范式转移 → 大变化
- 颗粒度 → 细节程度
- 飞轮效应 → 越转越快/良性循环
- 杠杆 → 省力的办法
- 势能 → 优势/积累
